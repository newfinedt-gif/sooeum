# Academy Finance PWA

학원 원장용 재무관리 PWA입니다.

## GitHub Pages 배포
1. 새 공개 저장소를 만듭니다. 예: `academy-finance-app`
2. 이 폴더 안의 파일들을 저장소 최상위(root)에 업로드합니다.
3. Settings → Pages → Build and deployment → Source를 `Deploy from a branch`로 선택합니다.
4. Branch는 `main`, Folder는 `/(root)`를 선택하고 Save 합니다.
5. 생성된 `https://<username>.github.io/academy-finance-app/` 주소를 휴대폰에서 엽니다.
6. 브라우저 메뉴에서 홈 화면에 추가/앱 설치를 선택합니다.

Supabase 프로젝트와 연결값은 app.js에 이미 설정되어 있습니다. publishable key만 포함되어 있으며 secret/service-role key는 포함하지 않습니다.
